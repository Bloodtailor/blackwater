# BLACKWATER — Canon Trace (everything built ↔ what the lore says about it)

> Created 2026-07-21 at the user's request: one document listing **everything that exists in the game** and how it relates to LORE.md — including the things the lore deliberately does *not* explain. Keep this current: when a session ships a player-visible thing, add its row in the same session.
>
> **How to read the LORE column:** *Explained* = the fiction gives it an identity · *Wrongness* = it exists to be wrong (a void feeds it, LORE §1.2) · *Unexplained-by-design* = the game refuses to discuss it and that refusal is the lore (LORE §1.1 "the site works") · *Pure gameplay* = a mechanic wearing set dressing; the lore covers its looks, not its rules · *Meta* = outside the fiction on purpose.
